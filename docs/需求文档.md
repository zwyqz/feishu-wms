# 需求文档（原始版，归档）

> 来源：客户提供的《鞋类采购报送管理系统 需求文档》。本文件仅作归档，实现与验收结论见
> [`需求验证报告.md`](需求验证报告.md)。

## 一、系统概述

系统面向鞋类销售场景，客户通过飞书报送采购需求，由 Agent（dsh）进行动态语义理解与交互式补录，
后台系统负责客户管理、订单汇总、出库导出与月度结算。

## 二、核心功能模块

### 1. 飞书消息接入与语义理解

- 客户通过飞书向系统机器人发送采购消息
- 消息格式不固定，由 Agent 进行动态语义理解，解析出结构化字段：
  - 客户名称、鞋型号、颜色、数量、尺码
- 示例：`a客户 型号b 黑色3双43码`、`再补两双白色55码的b款` 均可识别
- 支持同一客户每天多条消息，数量自动累加

### 2. 解析失败处理

- 当消息无法解析时，Agent 通过飞书自动回复客户，提示重新描述
- 可附上标准示例格式，引导客户规范表达

### 3. 客户信息维护与补录

- 后台可维护客户档案（名称、联系方式等基础信息）
- 当飞书消息中客户信息不全时，Agent 通过飞书主动追问，客户在聊天中回复完成补录，无需进入后台操作
- 补录完成的客户信息自动入库

### 4. 每日汇总与出库

- 后台支持不定时汇总当天各客户的订单数据（客户 × 型号 × 颜色 × 尺码 × 数量）
- 后台点击按钮导出 PDF 出库单/汇总单，用于出库作业

### 5. 客户单价管理

- 每个客户维护独立的单价体系（按客户 + 型号设定价格）
- 后台可新增、修改、查询价格

### 6. 月度结算

- 每月自动汇总各客户的采购数量
- 按「数量 × 该客户对应单价」计算金额，生成月度结算单
- 结算单导出为 PDF

## 三、系统角色

| 角色 | 主要操作 |
|---|---|
| 管理员 | 客户信息维护、单价设置、系统管理 |
| 库管 | 每日汇总、导出出库 PDF |
| 财务 | 月度结算、导出结算 PDF |

## 四、业务流程

```
客户飞书发消息 → Agent 语义解析
  ├─ 解析成功 → 信息完整 → 生成订单入库
  │            └ 信息不全 → Agent 飞书追问补录 → 生成订单入库
  └─ 解析失败 → Agent 飞书回复提示重新描述
后台不定时点击汇总 → 导出 PDF 出库单 → 出库
月末 → 生成月度结算单（数量 × 客户单价）→ 导出 PDF 结算单
```

## 五、暂不包含（如需可后续追加）

- 库存管理与出库扣减
- 订单修改/作废功能
- 收款状态、折扣、运费管理
- 定时自动汇总
